# V1 已知限制与后续项

- Topic Event 是一次对话主题片段，不等同于现实世界完整事件；后续可增加事件合并。
- Event 使用确定性模板，表达自然度弱于 StructMem 的 LLM 双阶段抽取，但成本和稳定性更好。
- Cross-Event 与 Profile 是异步最终一致，短时间内可能尚未反映最新消息。
- 默认无 LLM rerank，复杂查询的精排能力有限；先通过离线评测决定是否增加。
- SQLite 只支持单写 worker，不适合横向扩容。
- JSON 保存完整 embedding，磁盘开销较大；这是严格镜像要求的直接成本。
- 文件系统和数据库只能通过 Outbox 达成可恢复的最终一致，不能宣称跨介质强事务。
- 本地 Mem0 `main.py` 存在未提交修改；实现前需冻结补丁并纳入 provenance，避免“参考版本”漂移。

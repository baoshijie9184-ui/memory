# DesayMem 记忆后端部署与配置

## 1. 路径和环境

```text
仓库：/data/pengshuang/desaymem/apps/DesayMem_mem0
环境：/data/pengshuang/desaymem/envs/backend
配置：/data/pengshuang/desaymem/apps/DesayMem_mem0/.env
端口：20142
入口：desaymem.api.main:app
```

正确入口是 `desaymem.api.main:app`，不能使用不存在的 `desaymem.api.app:create_app`。

`LLM_PROXY_API_KEY` 只保护仓库中的可选 `scripts/llm_proxy.py`，不用该代理时可以留空；它不保护记忆 API。

```bash
chmod 600 .env
```

## 3. 本地模型适配修改

### 关闭 Qwen 思考

文件：

```text
src/desaymem/providers/llm/openai_compatible.py
```

调用参数包含：

```python
"extra_body": {
    "chat_template_kwargs": {"enable_thinking": False}
},
```

### Embedding 请求分块

文件：

```text
src/desaymem/providers/embedding/openai_compatible.py
```

设置 `_MAX_BATCH = 32`。这是每个 API 分块的文本条数。

### 中文语言保持

文件：

```text
src/desaymem/extraction/prompts.py
```

在 `ADDITIVE_EXTRACTION_PROMPT` 中加入：

```text
# Language Preservation
- Preserve the language of the original source message.
- If the source message is in Chinese, every extracted memory must be written in Simplified Chinese.
- Never translate Chinese content into Japanese, English, or another language.
- Preserve all numbers, units, names, product names, and proper nouns exactly.
```

修改应提交到 GitHub，避免服务器长期存在未提交代码而阻碍 `git pull`。

## 4. 启动

```bash
export PATH=/data/pengshuang/desaymem/envs/screen/bin:$PATH
screen -S memory-backend

cd /data/pengshuang/desaymem/apps/DesayMem_mem0
source /data/pengshuang/desaymem/envs/backend/bin/activate

uvicorn desaymem.api.main:app \
  --host 0.0.0.0 \
  --port 20142 \
  --workers 1
```

成功标志：

```text
Application startup complete.
Uvicorn running on http://0.0.0.0:20142
```

## 6. API 概览

| 方法 | 路径 | 功能 |
|---|---|---|
| GET | `/health` | 健康状态 |
| POST | `/v1/memories` | 写入并提取记忆 |
| POST | `/v1/memories/search` | 搜索记忆 |
| GET | `/v1/users/{user_id}/memories` | 列出用户记忆 |
| GET | `/v1/users/{user_id}/memories/{memory_id}/history` | 查看历史 |
| DELETE | `/v1/users/{user_id}/memories/{memory_id}` | 删除一条 |
| DELETE | `/v1/users/{user_id}/memories?confirm=true` | 删除该用户全部记忆 |

租户和用户共同决定隔离范围：`tenant_id + user_id`。调用方必须始终传递稳定且真实的两个 ID。

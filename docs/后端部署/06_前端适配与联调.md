# cockpit-frontend 适配与联调

仓库：`https://github.com/psile/cockpit-frontend`

## 1. 前端调用结构

```text
index.html
  1. POST 20142 /v1/memories/search → 召回用户记忆
  2. POST 本地 8767 /chat           → 结合记忆生成回复
  3. POST 20142 /v1/memories        → 异步保存本轮对话
```

记忆后端不直接承担普通聊天回复；Windows 本地 `llm_proxy.py` 负责调用 Qwen，并避免把 Qwen Key 放进浏览器 JavaScript。

## 2. Windows `.env`

```dotenv
LLM_API_KEY=<填写Qwen服务Key>
LLM_MODEL=memory-llm
LLM_BASE_URL=http://10.133.72.161:20140/v1
PROXY_PORT=8767
```

不要提交 `.env`。

## 3. 前端地址

登录页：

```text
记忆后端：http://10.133.72.161:20142
LLM代理：http://127.0.0.1:8767
```

可在 `index.html` 将 `apiUrl` 默认值从阿里云地址改为上述 20142 地址。

## 4. `llm_proxy.py` 修改

避免公司内网请求误走环境代理并提高超时：

```python
async with httpx.AsyncClient(
    timeout=120.0,
    trust_env=False,
) as client:
```

请求体增加：

```python
"chat_template_kwargs": {
    "enable_thinking": False
},
```

建议参数：`temperature=0.3`、`max_tokens=500`、`top_p=0.8`。这是普通车机回答，不需要沿用记忆后端的 2000 输出上限。

## 5. 启动

```powershell
cd "D:\agent memory\cockpit-frontend"
python -m pip install -r requirements.txt
python llm_proxy.py
```

保持代理窗口运行，再打开 `index.html` 或执行 `start.bat`。

## 6. 完整联调场景

第一轮：

```text
我开车时喜欢把空调设置为26度，请记住。
```

确认右侧记忆库出现简体中文记忆。

第二轮：

```text
我之前习惯把空调调到多少度？
```

确认页面显示参考记忆，回答包含 26 度。

第三轮冲突测试：

```text
从现在开始，我开车时把空调改成24度。
```

随后询问当前温度偏好，期望 24 度，而不是旧的 26 度。

第四轮隔离测试：切换 `user_id`，另一个用户不得检索到该偏好。

## 7. 常见问题

- `WinError 10061`：目标端口无监听，检查服务是否启动及地址。
- `Test-NetConnection=True` 但 HTTP 被关闭：检查 Uvicorn 是否监听 `0.0.0.0`，以及平台端口映射。
- LLM 代理失败：检查 20140、`.env`、Key、`trust_env=False`。
- 页面能聊天但不记忆：查看 20142 日志及 `/v1/memories` 返回。
- 重复写入被跳过：属于内容哈希去重，换用户或换内容测试。
